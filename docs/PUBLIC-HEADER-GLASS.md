# 公共导航栏的毛玻璃

顶部悬浮导航使用均匀的 CSS `backdrop-filter: blur(20px) saturate(1.12)`，搭配浅色和深色半透明填色、细边框及轻阴影。文字和操作按钮保持原有清晰前景，背景经过整体模糊透出。

根据用户对「毛玻璃效果」的澄清，先前的 SVG 折射、位移图生成、图像预加载和相关光学测试已移除。材质不依赖 JavaScript 尺寸计算或浏览器识别。原链接、选中项、悬停、键盘焦点、主题菜单和手机菜单逻辑保留。

不支持背景滤镜时使用高不透明度填色；减少透明度设置使用接近实色的背景。局部预览继续使用 `rsbuild.header-glass-preview.config.ts`，页面直接复用原首页与公共导航，不初始化账户或发起模型调用。
