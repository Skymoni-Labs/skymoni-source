# 公共导航栏的折射玻璃

范围为 `PublicHeader` 滚动后出现的浮动胶囊导航。链接、选中项、登录、主题菜单和手机菜单保留原逻辑；Skivu App 与资源页的独立导航不受影响。

材质采用单层背景采样：先轻微柔化背景，再对胶囊内缘作有界位移。位移场从外边界和中心平面逐渐归零，避免把整圈边缘变成粗灰带；色彩不拆成多个位移通道，避免端点的彩色断层。镜片背景、细边缘与高光负责可读性，文字和操作按钮不参与背景滤镜。

镜片宽高通过 `ResizeObserver` 按实际导航尺寸更新。位移图完成预加载和绘制后才启用 SVG 路径，期间使用 CSS 背景模糊；卸载、过期尺寸及加载失败会丢弃旧回调。Safari、Firefox 或不支持 SVG 背景滤镜的环境使用模糊回退。尊重减少透明度设置。

局部预览运行 `rsbuild dev --config rsbuild.header-glass-preview.config.ts`，访问 `http://127.0.0.1:18788/`，向下滚动使导航悬浮。预览直接复用原首页和导航组件，不经过账户初始化，其他目录使用公开/本地展示数据，不发起模型调用。`header-glass-review.tsx` 不作为生产入口。

验证包括：位移范围、对称性、中心与边界中性值；原选中项、悬停、键盘聚焦和导航回归；真实浏览器的浅色/深色、滚动挂载/卸载、390 像素手机布局及菜单展开。SVG 背景滤镜在 Chromium 中实际启用，其他浏览器回退未逐浏览器实测。
