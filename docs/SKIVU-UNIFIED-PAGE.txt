Skivu unified public page (2026-11-09)

Canonical address: https://skymoni.com/skivu/

The former brand page and resource hub share one React page with a cosmic
hero, interactive product preview, Android download, searchable plugin
catalogue, wallpaper previews, on-demand brand film and usage guides.
The main website navigation links to the canonical address.

Final art direction uses midnight blue, ice blue and violet nebula light.
The rotating planet, CSS orbital sculpture, floating functional links,
pointer parallax and Canvas constellation form the opening scene. Section
reveals, animated demo messages, a glass-blur slider, wallpaper gallery and
an independent beta portal vary the visual rhythm. Navigation, hero and beta
section all link to the existing application center. The beta center links
back to the current public download section instead of the historical APK.
There are no invented beta eligibility grants or automated applications.

Motion can be paused. System reduced-motion settings make the scene static;
Canvas frames stop while the page is hidden or the hero leaves the viewport.
Initial bookmark scrolling waits for asynchronous catalogue layout and
does not interrupt a visitor who has already started interacting.

The resource page continues to use the current public release and existing
validated public catalogues. It does not publish an App update, change
wallpaper selections or initiate model requests. Plugin installation and
permission confirmation remain inside the App.

Server contract: exact /skivu/ serves the current SPA index, while the
existing /skivu/ asset prefix continues to serve assets and the film.
/skivu, /skivu/index.html and /skivu-resources with an optional trailing
slash redirect to /skivu/ and preserve query parameters. Browser fragments
survive redirects. The legacy resource route also redirects client-side.
The old home, conversation, characters, appearance, ecosystem, film and
download anchors remain available. Feature links select the relevant demo.

The former standalone public/skivu/index.html is removed from source.
Install the exact canonical route before serving this frontend. Existing
static brand assets can remain available for historical builds and notices.

The film is instantiated only after the visitor opens it, requires a play
action and is removed on dialog close. Reduced-motion settings are honored.
