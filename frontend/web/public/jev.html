使用 Jev 做结构化判断

提交文本或 JSON 状态，定义需要判断的问题，获得分类、评分和概率。Jev 使用 System One 原生接口，不提供聊天文本或流式回答。

开始使用

  1. 注册或登录 skymoni，通过管理员分配或兑换码获得额度。
  2. 进入“API 密钥”，创建密钥，分组选择 typesafe（仅 Jev）或 default（全部模型）。
  3. 将自己的 skymoni Key 放入 Authorization 请求头，按下方格式调用。
  4. 在“使用记录”查看模型、Token 用量和扣费。
项目配置
请求地址POST https://skymoni.com/v1/systemone
鉴权Authorization: Bearer 你的_MONI_KEY
模型jev-latest、jev-preview、jev-1.13.0
当前价格（倍率 1）每百万输入 Token $0.042；输出 Token 免费

请求示例

以下命令适用于 Bash。替换为你的 skymoni Key；不需要 TypeSafe 官方账号或官方密钥。

export MONI_API_KEY='替换为你的_MONI_KEY'
curl https://skymoni.com/v1/systemone \
  -H "Authorization: Bearer $MONI_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "jev-latest",
    "state": "A customer cannot log in and urgently needs help.",
    "questions": {
      "urgent": {
        "type": "noul",
        "instructions": "Does the customer express urgency?"
      },
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this?",
        "criteria": {"support": "Technical support", "sales": "Sales inquiries"}
      },
      "priority": {
        "type": "score",
        "instructions": "How urgent is this request?",
        "criteria": ["Low", "High"]
      }
    }
  }'

读取结果

answers.urgent.noul 是“是”的概率；answers.department.choice 是选中的分类；answers.priority.score 是评分。Choice 和 Score 还返回概率分布与置信度。usage 提供输入和输出 Token 数，model 提供实际服务的模型版本。

价格按美元计价的站内额度扣除。例如 364 个输入 Token 收费 $0.00001529，输出不收费。显示位数可能隐藏微小金额，实际账本按 8 位美元小数结算。价格如有调整，以 skymoni 当前渠道价卡为准。

常见错误

状态码处理方法
400 / 422检查 model、state、questions 和问题类型；不要使用聊天请求体或 stream:true。
401检查 skymoni Key 是否正确且已启用。
403检查余额、分组权限和模型白名单。
429检查 Key 限额，或按 Retry-After 等待后重试。
502 / 503上游不可用或站点配置未就绪，请联系管理员。

当前使用 HTTPS 域名。英文是 Jev 表现最好的语言，中文场景应使用自己的样本验证。概率与置信度不保证答案一定正确。

官方 Python SDK 接入

安装 typesafe-sdk，使用自己的 skymoni Key。SDK Base URL 为 https://skymoni.com/typesafe，不追加 /v1。支持模型列表与三种原生决策。

import os
from typesafe_sdk import TypeSafeClient, Noul
with TypeSafeClient(
    api_key=os.environ["MONI_API_KEY"],
    base_url="https://skymoni.com/typesafe",
    model="jev-latest",
) as client:
    print(client.models.list())
    result = client.system_one(
        state={"message": "I cannot log in. Help now."},
        questions={"urgent": Noul(instructions="Is urgent help requested?")},
    )
    print(result.answers, result.usage)

后台连接测试已适配原生决策。当前插件支持批量问题；网关保护上限为每请求 4096 个问题和序列化 JSON 1000000 个字符，官方上下文限制仍按 Token 校验。
