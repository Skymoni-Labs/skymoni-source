宇宙主视觉与空间站

星球银河背景由本项目使用 OpenAI 图像生成工具独立生成。首屏 3D 星球保留该图的构图、背景与边缘光，转动的内部地表和云层使用下述 NASA 完整经纬贴图，并作冰蓝与淡紫调色。不是从单幅插画恢复背面，也不是实时天文影像。

国际空间站展馆接入 iss-3d 项目；太阳能翼、实验舱、机械臂及地球海洋、近似大陆、云层和冰盖均由 Three.js / TypeScript 代码生成，没有加载外部 3D 模型文件。主要舱段按 NASA、JAXA、CSA 公开资料校准，附属结构简化；是结构示意，不构成工程级 1:1 数字孪生或实时轨道视图。

页尾电影感宇宙全景

页尾银河、远月、星球地平线与日出全景由本项目使用 OpenAI 内置图像生成工具，参考既有原创主视觉的配色与质感独立生成。 内部星球地表与云层由完整球面贴图连续转动；银河、远月、日出及大气边缘保留插画构图。缓慢推进、视差与星光动效由 CSS 和网页交互实现，不是实时天文影像。 查看最终提示词与资产记录。

旋转地表与云层 · NASA 素材记录

当前动态星球使用的地表、独立云层，以及保留的静态东半球素材来自 NASA Blue Marble（2002）。 这些影像由历史卫星观测合成，日照和旋转为视觉编排，不是实时地球影像。 素材署名：NASA Goddard Space Flight Center、Reto Stöckli、Robert Simmon。

按 NASA 媒体使用说明使用，不表示 NASA 对 Skivu 的合作或背书。 查看原始下载地址与文件记录。
