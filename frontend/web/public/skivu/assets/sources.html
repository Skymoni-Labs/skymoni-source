宇宙主视觉与空间站

星球银河背景由本项目使用 OpenAI 图像生成工具独立生成。首屏 3D 星球以该图作为正面投影纹理，保留原来的配色、云层与边缘光线；单幅图没有记录的部分用连续镜像延展，不代表真实地理恢复。

国际空间站、太阳能翼、实验舱、机械臂及地球海洋、近似大陆、云层和冰盖均由 Three.js / TypeScript 代码生成，没有加载外部 3D 模型文件。主要舱段按 NASA、JAXA、CSA 公开资料校准，附属结构简化；是结构示意，不构成工程级 1:1 数字孪生或实时轨道视图。
