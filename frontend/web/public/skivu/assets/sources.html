当前宣传页 · 星门航行

银河环带的流动直接复用原有首屏图片作为本站纹理，通过局部切向流场和双相位采样实现连续运动。中央暗区、月亮和前景保留原位；原始图片文件未修改。暂停动态、减少动态偏好和兼容模式仍可静态观看。

当前宣传页采用原创「星门航行」视觉。首屏星门全景由本项目使用内置 OpenAI 图像生成工具独立生成，没有提供外部照片、电影画面或第三方模型作为输入；画面是虚构宇宙概念艺术，不是天文观测。既有原创银河图继续作为星空远景。

本站原创 Three.js / TypeScript / Shader 代码为六段内容添加不同动态视觉：星门微尘、光子河流、双星光环、极光玻璃带、稀疏分支星图与页尾日出地平线。页面按正常文档顺序滚动，共享透明画布切换场景；没有加载外部模型或 NASA 地表纹理。代码视觉是艺术演绎，功能交互为示意。WebGL 不可用时保留 CSS 宇宙艺术视觉。历史版本和独立空间站展馆使用的素材、资料与许可继续保留在下方。

历史宇宙插画素材

历史首屏星球银河插画，以及历史页尾银河、远月、星球地平线与日出全景，均由本项目使用 OpenAI 内置图像生成工具独立生成。页尾图参考既有原创主视觉的配色与质感。 这些素材及其记录仍随项目保留，不代表当前宣传页加载了历史首屏/页尾旋转入口，也不是实时天文影像。 查看最终提示词与资产记录。

历史旋转地表与云层 · NASA 素材记录

历史星球入口使用的完整经纬地表、独立云层，以及保留的静态东半球素材来自 NASA Blue Marble（2002）。 这些影像由历史卫星观测合成，历史版本的日照和旋转为视觉编排，不是实时地球影像；当前 R10 宣传页不加载这些贴图。 素材署名：NASA Goddard Space Flight Center、Reto Stöckli、Robert Simmon。

按 NASA 媒体使用说明使用，不表示 NASA 对 Skivu 的合作或背书。 查看原始下载地址与文件记录。

保留的独立空间站展馆

国际空间站展馆接入用户提供的 iss-3d 项目；太阳能翼、实验舱、机械臂及地球海洋、近似大陆、云层和冰盖均由 Three.js / TypeScript 代码生成，没有加载外部 3D 模型文件。主要舱段按 NASA、JAXA、CSA 公开资料校准，附属结构简化；是结构示意，不构成工程级 1:1 数字孪生或实时轨道视图。独立展馆保留结构资料与自由探索，当前宣传页不再嵌入该展馆。资料原始链接与真实性边界见上述场景源码运行说明。
