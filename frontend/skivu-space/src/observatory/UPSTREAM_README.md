# 国际空间站 · 交互式 3D 数字展馆

> 地球之上，人类的另一扇窗。

使用 **Three.js + TypeScript + Vite** 从零构建的国际空间站三维交互页面。站体结构、地球纹理、太阳翼电池片、舱段舷窗、机构标识、星空与动画全部由代码生成，不依赖任何外部模型、图片或字体资源。

## 本地运行

环境要求：**Node.js 20.19+（或 22.12+）**，支持 WebGL2 的现代浏览器。

```bash
# 1. 进入项目目录
cd iss-3d

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev
```

打开终端输出的地址（默认 `http://localhost:5173`）。

生产构建与本地预览：

```bash
npm run build
npm run preview
```

构建产物位于 `dist/`。首次打开场景时会实时生成约 1536×768 的地球颜色/粗糙度/云层遮罩纹理，通常需要 1–3 秒；加载动画会覆盖该过程。

## 模型与场景

- **比例**：`1 scene unit = 1 metre`；站体按公开的舱段/桁架/太阳翼尺寸量级搭建，地球半径 `6,371 km`，空间站位于其上方 `408 km`。
- **站体模块**：主桁架、四对太阳翼、散热器、命运号、希望号（含舱外实验平台）、穹顶舱、和谐号、团结号、宁静号、哥伦布号、曙光号、星辰号、寻求号气闸、加拿大臂 2，以及龙飞船与联盟号访问飞船。
- **细节**：金属蒙皮、金色多层隔热材料、对接环、舱门、舷窗、扶手、电缆槽、ORU 设备箱、SSRMS 关节、机构铭牌和危险警示条。
- **地球**：程序化海陆/冰盖颜色贴图、粗糙度贴图、烘焙云层，以及独立的动画云层与大气边缘辉光 Shader；海洋、云层与冰盖均在运行时生成。
- **动画**：太阳翼缓慢太阳跟踪与轻微弹性摆动；加拿大臂低频微动；地球与云层缓慢转动；加载与镜头飞行过渡。
- **光照**：方向光、补光、半球光与 PCF 阴影；ACES 色调映射。

模型是对国际空间站构型的可视化重建，用于展示与交互体验；并非官方 CAD 工程模型，细节位置可能与在轨最新构型存在差异。

## 项目结构

```text
iss-3d/
├─ index.html                 # 页面结构与 UI 骨架
├─ src/
│  ├─ main.ts                 # Three.js 场景、相机、交互、UI、加载流程
│  ├─ station.ts              # 空间站全部程序化模块与细节
│  ├─ Earth.ts                # 地球、云层 Shader、大气辉光
│  ├─ textures.ts             # 程序化地球/太阳翼/铭牌/散热器纹理
│  ├─ data.ts                 # 模块资料、导航与特写镜头配置
│  ├─ style.css               # 深色科技风 UI 与响应式布局
│  └─ vite-env.d.ts
├─ vite.config.ts
├─ tsconfig.json
└─ package.json
```

## 设计备注

- 左侧信息面板、右侧模块导航与底部控制栏使用玻璃拟态与细网格 HUD 风格；小屏幕下左侧面板可滚动，右侧导航变为可横向滑动的模块标签。
- 场景中的每个模块均为独立 `Group`，通过 `userData.moduleId` 与右侧导航、悬停射线检测和信息面板联动。
- 浏览器窗口尺寸变化时会重新计算全景构图；在模块特写中不会强制打断当前视角。
