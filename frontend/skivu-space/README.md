# Skivu 宇宙交互场景

独立的 Three.js + TypeScript 项目。当前宣传页采用「星门航行」方向，以 `src/gate.ts` 统一绘制贯穿全页的原创光线雕塑，六个场景随自然网页滚动切换。首屏以原创星门全景为背景，功能章节分别使用光子河流、双星光环、极光带与开放星图，页尾以巨大的日出地平线收束。内容按正常文档顺序阅读，当前不加载 NASA 地表纹理。用户提供的 `iss-3d`、已发布的 R9 引力场及此前星球入口保留为历史源码和独立展馆。未修改 App、后端或整站前端构建配置。

## 本地运行

开发/构建需要 Node.js 22.12+（本机已验证 Node 24.11.1）。发布后的页面只有静态 HTML、CSS、JavaScript 与本站资源，访问者和线上静态服务器不需要 Node 服务、API Key、环境变量或额外模型文件。

浏览器三维视图需要 WebGL 2。当前宣传页在不支持、着色器失败或上下文丢失时保留 CSS 宇宙艺术视觉；历史空间站展馆提供明确标记的二维结构预览。资源需经 HTTP/HTTPS 提供，不使用 file:// 直接打开模块。无需修改浏览器安全设置。

```powershell
cd frontend/skivu-space
npm ci
npm run dev
```

打开 http://127.0.0.1:18941/ 查看独立空间站。`index.html` 为页面，兼容引导入口为 `src/observatory/boot.ts`，按需载入三维入口 `src/observatory/main.ts`；该目录内的 `station.ts` 生成空间站，`Earth.ts` 管理地球，`textures.ts` 生成纹理，`data.ts` 管理资料和特写，`style.css` 为界面样式。`IMPORTED_SOURCE.json` 记录接入前六个源文件的 SHA，`UPSTREAM_README.md` 保留提供项目的说明。没有复制浏览器配置、缓存、截图或 node_modules；原始提供目录保持不变。

## 构建与宣传页集成

```powershell
npm run build
cd ../web/public
python -m http.server 18940 --bind 127.0.0.1
```

宣传页：http://127.0.0.1:18940/skivu/ ，独立空间站：http://127.0.0.1:18940/skivu/interactive/ 。构建只更新专用的 `frontend/web/public/skivu/interactive` 目录。空间站及其纹理由代码生成，没有 GLB/GLTF/OBJ，Three.js 打包在本站，运行时不依赖第三方 CDN。

独立空间站展馆支持左键/单指旋转，滚轮/双指缩放，右键/双指平移。右侧菜单与模型点选均可切换特写和资料，底部可切换自动旋转、重置、全屏。历史嵌入方式曾使用“退出交互”或 Escape 恢复网页滚动；当前 R10 宣传页不嵌入空间站、不捕获拖拽或滚轮控制，使用正常网页滚动。

## 星门航行（当前宣传页）

`src/gate.ts` 是当前宣传页唯一三维入口，在固定的 `#gate-viewport` 透明共享画布中绘制银河环带流动、光子河流、双星光环、半透明极光带、稀疏分支星图及日出地平线。首屏主视觉 `stargate-panorama-20261026.webp` 由本项目使用内置 OpenAI 图像生成工具原创生成；R11 的 `src/galaxy-flow.ts` 直接复用同一张本站图片作为纹理，按原图倾斜环带的切线方向做局部平流。双相位采样平滑衔接循环，保留中央暗区、月亮与前景；不旋转整张背景，不另画覆盖原图的洞口。动态画布按 CSS 背景的实际裁切、缩放、鼠标视差和暗角对齐，首次载入、失败或兼容模式仍显示原始图片。星空远景继续复用既有原创银河图。全部宇宙视觉都是艺术演绎，不对应真实天体、实时遥测或产品语音能力；不依赖外部模型、第三方贴图/CDN、API Key 或新增收费服务。

六个镜头对应首屏、多模型对话、角色配置、个性外观、开放插件与页尾下载。HTML 内容按正常文档顺序阅读；页面脚本通过 `gate:scene` 事件传入 `{ scene: 0..5, progress: 0..1 }`，三维入口平滑切换不同光线雕塑。页面影片段延续开放生态镜头。初始场景从根元素 `data-gate-scene` 读取；完成首帧后发出 `gate:ready` 并添加 `.webgl-ready`，失败时添加 `.webgl-failed`。`/skivu/?gate=css` 可主动检查 CSS 兼容视觉。新星门图的生成方式、提示词与素材边界记录在 `../web/public/skivu/assets/stargate-panorama-20261026.source.txt`。

固定种子确保星尘、远星与分支星图一致。桌面 DPR 上限1.35、目标30fps，粗指针或窄屏 DPR 上限1、目标24fps；保留帧预算余数，后台/离屏/全局暂停时停止动画。系统减少动态偏好下仍绘制静态首帧，切换章节直接定位，不持续请求动画帧。全局暂停事件沿用 `skivu-motion-change`，并兼容 `skivu:motion`；暂停状态由根元素 `.motion-paused` 决定。实际速度取决于设备，不把浏览器窄屏预览等同于实体手机 GPU 验收。

品牌云标识与云朵角色沿用现有资产。产品交互是宣传示意，不冒充真机录屏或网络请求；只描述已有对话、模型选择、角色、外观与开放插件能力。内测审核与管理员手动分配额度的边界保留。现有40秒品牌影片沿用且默认静音，其许可链接保持。

## 尺度与真实性边界

空间站坐标 1 单位 = 1 米，主要舱段使用公开长度与直径，主桁架约 94 米，阵列横跨约 109 米。命运号、希望号及其物流/暴露平台、穹顶七窗、机械臂与主阵列分别建模。舱门、栏杆、蒙皮、机构文字等为程序化细节。附属舱段、连接关系与设备经过简化，整体不构成工程级 1:1 数字孪生，也不声称是当前每个在轨附件的完整配置。

地球沿用 `iss-3d` 的程序化海陆、云层与冰盖，非卫星照片。地球半径 6,371,000 米、示意高度 408,000 米，使用对数深度缓冲。接入时为云层和大气自定义 Shader 补齐相同的对数深度写入，避免它们与实体地球深度不一致形成白色硬边。不是实时星历或遥测。

历史首屏入口 `src/hero.ts` 保留原有 1672×941 插画的椭圆轮廓（中心 1400,554；半径 448,420）、银河与已烘焙的大气高光。插画没有背面；为了避免循环裁切图在四分之一圈时拉成长带，内部表面曾改为 NASA Blue Marble 完整经纬地表和独立云层，以真实球面经纬连续取样并作冰蓝、淡紫调色。`src/planet-surface.ts` 统一该历史入口的纹理加载和球面 Shader。转动后内部地理/云层会变化，不是单幅插画的精确三维复原。原图边缘光固定，不会转入内部形成第二个亮圈。WebGL 不可用时保留静态原图。R10 当前宣传页不加载该入口。

历史页尾入口 `src/finale.ts` 使用独立球面、完整 NASA 地表及云层，沿倾斜轴持续旋转。固定光照和独立大气壳不随地表贴图旋转；背景复用既有原创银河图。GPU 不可用或上下文丢失时保留原先银河、远月、日出的静态全景。插画提示词见 `../web/public/skivu/assets/universe-finale-20261025.source.txt`，NASA 素材原始地址、字节和 SHA 见同目录 `earth-blue-marble.source.json`；署名 NASA Goddard Space Flight Center、Reto Stöckli、Robert Simmon，遵循素材声明页列出的 NASA 媒体使用说明，不代表机构背书或实时影像。R10 当前宣传页不加载该入口或其 NASA 纹理；旧 `src/earth.ts` 和早期 `src/station.ts` 同样不是当前宣传入口。

## 历史空间站：动画与性能

固定种子星空，桌面约 30 fps、手机约 24 fps 上限，限制像素比。不可见场景与后台暂停，宿主动态开关控制星球、空间站及页尾 CSS 动效。桌面阴影图初始化一次，细小太阳翼运动不反复刷新阴影贴图。手机关闭阴影和多重采样、地球纹理降至 512，按材质与顶点属性布局合并静态同级网格；保留模块分组、太阳翼轴和机械臂动画边界。实际速度取决于设备，尚未进行实体手机 GPU 测试。

接入保留拖动、平移、缩放、导航特写、键盘1—6/R、自动旋转与全屏。相机根据侧面信息面板和下方导航计算可见区域；手机不会将模型主体放在面板下面。嵌入时默认关闭滚轮缩放，点击模型或导航进入交互，退出按钮/Escape恢复浏览。父子窗口消息校验同源及窗口来源。减少动态效果下仍可操作模型，镜头切换直接到位。参考分析见 `DESIGN_REFERENCES.md`。

## R5 手机首帧与兼容恢复

首帧直接绘制后才撤下加载层，不等待宿主消息。父子双向就绪握手，返回页面重新同步；子页面也独立观察自身可见性。初始化等待帧带超时，避免手机暂停离屏 iframe 的 RAF 后一直停在加载中。手机视图与桌面视图仍共享同一套完整结构。

三维导入、WebGL 2、着色器或上下文中断时使用内联 SVG 二维结构示意，不伪称三维录屏。导航仍可查看模块资料，提供重新加载入口。可用 `interactive/?compat=1` 主动打开兼容预览，重新加载按钮移除此参数。HTML 也包含无模块浏览器与超时兜底。兼容模式不提供三维旋转/缩放控制。

本轮在桌面浏览器的 390×844 视口验证手机质量分支、无宿主通知的 iframe 首帧和导航、兼容预览及资料切换；不等同于实体手机 GPU 验收。构建目标为 ES2018。当前页仍保留原有减少动态效果选项。


## R7 空间站功能导览（历史布局，已由 R8 替代）

宣传页 `station-tour.css` / `station-tour.js` 将四个产品功能章节置于同一座粘性定位的空间站场景中：对话中枢、角色舱、光影舱和开放插件拓展坞。滚动和可键盘访问的章节锚点更新当前功能、进度和相机目标。`tour=skivu` 只在嵌入模式启用，隐藏物理结构 HUD、禁用 OrbitControls 捕获；独立展馆行为保留。宿主消息校验来源窗口、同源以及预定义章节白名单。初始化完成前记住当前章节，3D 就绪后应用，避免深链接进错章节；相机数据复制后使用，不修改共享模块定义。动画暂停或减少动态偏好时，相机直接定位。

桌面模型停留左侧、产品交互沿右侧展开；900px 以下收为顶部紧凑场景、下方顺序内容，不阻止网页滚动。父页动态暂停、离屏及后台控制沿用 R5。首页跟随视差从水平9/垂直7px增加到23/16px，保留平滑追随、鼠标离开回中和暂停归零。

完整经纬贴图取样使用修正后的跨经线梯度，避免 atan 经度分界在旋转中触发粗糙 mip 采样并形成虚线暗缝。


## R8 单舱滚动舞台与运行配置（历史）

`station-tour.js` 按固定舞台的滚动位置计算唯一当前章节。章节容器位于舞台内部，旧内容先完整 hidden/inert 后再显示新内容；没有前后文案穿过同一画面，也不让隐藏控件参与键盘焦点。向上滚动可回看；点击任意章节直接定位对应滚动段，舞台不动，内容淡入、镜头缓动，不闪过中间章节。深链接、浏览器前后退和视口调整均同步当前章节。

渲染窗口只占实际模型区域：桌面左侧56%，手机上方30%；不再绘制被产品说明覆盖的区域。`src/observatory/runtime.ts` 集中管理模式、章节映射、DPR、帧率、抗锯齿和阴影。根据粗指针、小渲染窗口、低CPU并发或 `quality=low` 使用轻量档；低档DPR上限1、24fps、低分辨率纹理和静态网格合并。宣传模式倾向低功耗、不使用阴影，标准档DPR上限1.25/30fps；独立展馆标准档上限1.6，保留自由控制。

低档可在独立展馆使用 `interactive/?quality=low`。WebGL 2失败、着色器错误、加载异常与上下文丢失使用标注的二维结构预览；宿主页显示实际状态，并提供“重试三维”按钮。`/skivu/?station_compat=1#characters` 可主动检查嵌入兼容模式；重试会移除iframe的compat参数。父子消息均校验来源窗口与同源。

全局暂停时暂停场景和进行中的镜头，恢复时补偿暂停时间。减少动态偏好下新镜头直接定位；不因暂停而持续请求过渡帧。原提供的 `E:/dshgf/iss-3d` 仍只读，修改只在本项目副本中。


## R9 原创星际引力场（历史宣传模块，已由 R10 替代）

`src/cosmos.ts` 为独立入口，直接在宣传页的 `#cosmos-viewport` 内绘制，不使用iframe或空间站模型。程序化Shader气态星球、独立大气、分层轨道环、三颗卫星、固定种子远星、流星轨迹和开放星图构成五段场景。原有原创银河作为CSS远景。场景是艺术演绎，不是真实天体/遥测。

`cosmos-story.js` 使用同一个阅读区按滚动位置显示唯一章节，事件 `skivu-cosmos-change` 驱动相机、色彩、卫星和星图状态的渐变；初次渲染从DOM读取当前章节，并通过ready事件重同步。章节、锚点、返回与刷新沿用已验证的定位逻辑。`gravity.css` 为该模块独立样式，不加载旧station-tour样式。模型区域使用overflow:clip，避免键盘或自动定位将固定舞台滚偏。

渲染按视口限制DPR（手机1、桌面1.35）、24/30fps目标，保留帧预算余数。离屏/后台停止RAF，全局动态开关与减少动态偏好控制星球、流星、镜头和CSS层。无WebGL2、Shader失败或上下文丢失时保留CSS星球/星环视觉，功能控件正常；`/skivu/?cosmos=css#overview` 可主动检查兼容视觉。没有新增模型/CDN/API或付费服务依赖。

所有品牌/产品文案只描述已有功能，保留交互示意、管理员审核与手动分配额度的边界。独立ISS地址和原始提供目录保留。

R9b 补充：721–900px 的中间屏幕保持左右构图（沿用62px页头高度），720px以下使用上下构图。兼容星球按高度与宽度共同限幅，避免平板横向过度放大。只更新静态HTML/CSS，无需重新构建Three.js。
